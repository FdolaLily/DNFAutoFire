### 2026-9-25 v0.3.0.5

- [奔跑]修复按住三个方向、或反向后再点按上下时，两个方向每 30ms 轮流抬起按下、无限抖动的问题：同一时刻只让一个方向双击，其余按住的方向保持按下并在其完成时加入；被打断的双击最多重发 3 次，之后保持行走。
- [奔跑]连发后奔跑：先按住技能再按方向，或搓招保护期间按了技能，技能松开后仍按住的方向会按搓招保护起跑，不再一直走路。
- [奔跑]奔跑中放技能：连发键、已启用的旅人 / 战法 / 剑宗触发键和连招全部结束后立即补双击恢复奔跑；恢复过程中再次按技能、多个技能交替、斜向奔跑时技能期间松开一个方向都不再丢失奔跑。其他按键（跳跃、道具、未加入连发的技能等）松开后按搓招保护重新起跑，不再误以为仍在奔跑。
- [奔跑]同时按住左右（或上下）时后按的方向生效并起跑，松开后恢复先按的方向。
- [奔跑]识别玩家自己的快速双击（第一下不超过 250ms、200ms 内再按下），不再额外补发一次抬起 / 按下造成停顿。
- [奔跑]在游戏内开关奔跑或快速切换方案时按着方向键：开启后直接开始起跑计时；关闭后方向键交还游戏继续行走，不再停在原地。
- [奔跑]锁屏、Ctrl+Alt+Del、UAC 等切换到安全桌面后视为所有键已抬起，DNF 重新获得焦点时清除丢失抬起的按键，避免奔跑一直失效。
- [奔跑]方向键与连招触发键或已启用职业的技能键相同时，连招 / 职业优先（此前奔跑会吞掉该键，剑宗等功能失效）；奔跑设置中提示“方向键被连招/职业占用”，设置方向键时拒绝此类按键。

验证：输入状态机新增逐条回归，并穷举约 195 万条按键序列（停手后输出静止、只有最新的方向到达游戏、单独按住的方向最终奔跑、技能按住期间不奔跑、与简化 DNF 双击模型一致）；另用离线搜索覆盖 6,400 万条序列（含连招、焦点切换、不同搓招保护与脉冲时序），未发现违例。配置、迁移、界面、调度、服务逻辑、程序更新及成品自检在 Wine 下全部通过；单实例与构建工具脚本未在云端运行。自动测试不注入真实键盘输入，游戏内效果仍需实测。
