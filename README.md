# DAF · DNF 连发工具

chenyu 魔改版。面向 Windows 10/11 x64 的 DNF 辅助工具，纯 C++ / Win32 单 EXE，无需额外安装运行环境。

[下载最新版本](https://github.com/FdolaLily/DNFAutoFire/releases/latest) · [图文操作手册](docs/操作手册.md) · [更新日志](docs/更新日志.md)

## 主要功能

- **按键连发**：多方案、多键位，支持职业辅助；按下 / 抬起间隔可调，默认 7+7ms。
- **一键奔跑与连招**：可自定义方向键、触发键和时序，一键奔跑默认关闭。
- **后台服务**：随 DNF 启动 / 退出连发，管理指定后台进程与游戏优先级。
- **游戏工具箱**：禁用 / 恢复部分组件、清理日志缓存、修复黑屏，操作前需关闭游戏。
- **游戏内快捷操作**：Alt+F12 开关连发、F10 开关一键奔跑、Alt+` 快速切换方案，开关后在游戏右下角提示状态（不注入游戏、不抢焦点）。
- **界面与配置**：明亮 / 暗黑主题、托盘运行（图标绿灯运行中、红灯未启动）；设置自动保存到程序旁的 `config.json`。

按键辅助仅在 DNF 前台生效，不读写游戏内存、不联网、不记录键盘文本。

## 开始使用

1. 将 `DNFAutoFire.exe` 放在固定目录，双击并允许管理员权限。
2. 选择方案和连发按键，按需开启奔跑或连招，打开 **启动连发**。
3. 需要随游戏自动运行时，点击启动开关左侧的 **后台服务 → 安装并启动**。

后续打开默认直接开始连发并隐藏到托盘，双击托盘图标可打开界面。更新时双击新版本按提示操作，或使用 **后台服务 → 程序版本 → 从文件更新…**。

**删除或移动程序前**：打开连发 → **后台服务 → 卸载** → 从托盘 **退出**，避免文件被服务占用。详细设置与常见问题见 [操作手册](docs/操作手册.md)。

## 开发

运行 `./scripts/build.ps1` 编译并执行回归测试；源码变化时自动递增版本，成品位于 `build/release-<版本>/`。版本与待发布说明见 [Version](Version)，推送匹配的 `v*` 标签才创建 GitHub Release。
